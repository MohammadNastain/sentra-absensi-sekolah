# ADR 0007 — Default Autentikasi & Runtime (D-25, D-34, D-37, D-38–D-41)

- **Status:** Diterima (17 Okt 2026, persetujuan pemilik produk)
- **Terkait:** ADR 0004 (identitas & keanggotaan), ADR 0008 (email), `TAHAP_1_FONDASI.md`

| ID | Keputusan | Alasan | Konsekuensi | Cara pengujian |
|---|---|---|---|---|
| D-34 | Konteks sekolah lewat path `/api/v1/schools/{school}/…`. **Setiap request** memverifikasi keanggotaan aktif + izin peran. ID di URL tidak pernah dipercaya begitu saja. | Eksplisit, aman per tab, terlihat di log | Semua rute tenant berada di bawah prefiks; middleware wajib | T01–T07, T14 (dua tab), matriks rute T08–T09, RLS T10–T11 |
| D-37 | Undangan & reset password via email dengan verifikasi kepemilikan. Admin sekolah **tidak** bisa membuat password, mengubah email/password, atau menambahkan keanggotaan tanpa persetujuan pemilik akun. | Mencegah pengambilalihan akun lintas sekolah (R18) | Butuh layanan email (ADR 0008) | I01–I07 |
| D-25 | TOTP 2FA wajib untuk Super Admin: rute platform ditolak sampai 2FA terkonfirmasi dan tantangan 2FA lulus di sesi tersebut. | Akun dengan dampak lintas tenant | Super Admin perlu aplikasi authenticator | A08, A09 |
| D-38 | **Laravel Fortify** (headless) untuk login, 2FA, dan reset password. Kompatibilitas diperiksa: Fortify v1.41.0 mensyaratkan `illuminate/* ^11|^12|^13` dan PHP ^8.2, cocok dengan Laravel 13 + PHP 8.5. Kecocokan aktual dibuktikan oleh test suite. | Kode auth yang matang | Rute bawaan Fortify diberi prefiks `/api/v1/auth` dan view dimatikan (headless) | A01–A09 lulus di CI |
| D-39 | Cek password bocor dengan `Password::uncompromised()` bawaan Laravel. Model *k-anonymity*: hanya **5 karakter pertama hash SHA-1** yang dikirim ke layanan Have I Been Pwned; password mentah dan hash lengkap tidak pernah dikirim. | Mencegah password yang sudah bocor | Butuh akses internet keluar; bila layanan tidak tersedia, validasi **tidak** menggagalkan pendaftaran (perilaku bawaan) dan kejadian itu dicatat di log. Di test diganti fake HTTP. | Test memastikan request keluar hanya memuat prefiks 5 karakter (HTTP fake + assert) |
| D-40 | Redis lewat **predis** (`predis/predis` 3.x, murni PHP). Dibutuhkan untuk session, cache, rate limiter, dan queue. | Tidak butuh ekstensi PECL yang kompatibilitasnya dengan PHP 8.5 belum terverifikasi | Sedikit lebih lambat dari phpredis, tidak signifikan pada skala ini | Test integrasi: session & rate limiter berjalan di Redis container |
| D-41 | `apps/api/vendor` disimpan di **named volume Docker** (`api-vendor`), bukan di disk Windows. Aplikasi JS (`apps/web`) berjalan di **Node host**, sehingga `node_modules` hanya ada di host dan tidak dipakai container. | Performa I/O di Windows; tidak ada dependency yang dipakai bersama host dan container | IDE di host tidak melihat `vendor/`. Bila perlu autocompletion, salin dengan `docker compose cp`. Composer **hanya** dijalankan di container. | `verify-dev-env.sh` memeriksa vendor ada di volume; CI menjalankan composer di container yang sama |
